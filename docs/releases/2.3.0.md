# What's new in 2.3.0

Zana 2.3.0 makes it easier to follow your agents from your phone. A simpler mobile menu, roomier composer, and full-screen tools keep the conversation in focus. New connection options let your phone reach your Mac over a local network, Tailscale, or a self-hosted Heroku relay.

## New

- **A simpler mobile home.** Find all your agents in one searchable menu, with project labels, live working indicators, and clear attention states. New agent, Inbox, and Agents are close at hand; More opens a searchable picker for your other tools and plugins.
- **Three phone connection methods.** Settings → Phone now offers Local network, Tailscale, and Relay. Local network remains the default. Tailscale uses your tailnet's HTTPS Serve address; Relay connects your desktop through an authenticated outbound tunnel and can run alongside the existing website in its Heroku Docker app.
- **Help installing the phone app.** Phone settings explains the device setup steps and can open an agent with an installation prompt prepared for you.
- **Canvas on mobile.** Choose Kanban, List, or Canvas from Agents. Opening an agent gives its thread or terminal the screen.

## Improved

- **More room for conversations.** Mobile agents use one header row. Menus and side panels fill the screen, with clear close and back controls. Long sent messages have a compact preview with Show more, and desktop git/review strips stay out of the mobile composer.
- **A composer built for touch.** Larger harness and model pickers, an expanded writing view, and readily accessible Edit/Full access controls make it easier to configure and send a message. Secondary run settings use a clearer layout.
- **Inbox and documents on small screens.** Cleaner inbox rows and detail actions reduce clutter. Selecting a Library document opens a full-width reading view with a way back to the list. Scheduler, Tasks, and PR Monitor also use more compact mobile layouts.
- **Settings and navigation.** Search stays available as you scroll the menu. Settings has a consistent return path, and Share, Reload, and This device are tucked into the menu's actions.
- **Remote connection recovery.** Relay connections use heartbeats and reconnect after interruptions. Paired phone sessions can reconnect after a relay restart while the desktop gateway stays running.
- **Modern threads in the menu bar.** The desktop menu bar popover includes Modern threads alongside CLI Agents.
- **Salesforce project creation.** Create a Salesforce project after signing into an org, with the project and org connection kept together.
- **Git marketplace sources.** Add supported Git repository catalogs when browsing and installing plugins.

## Fixed

- **Mobile panel themes.** Agent side panels and diffs follow the app's light or dark theme.
- **Voice authentication.** Voice input recognizes the desktop's supported Codex sign-in storage instead of incorrectly asking an already signed-in user to log in again.
- **Plugin installation recovery.** Failed plugin replacements roll back cleanly, and Tasks styles stay contained within the plugin.

---

_Agents continue to run on your Mac, which must remain awake and online. Tailscale requires both devices to join the same tailnet and a configured Serve address. The self-hosted relay currently supports one desktop on one always-on instance; its operator can inspect relayed traffic. Configure a connection in Settings → Phone, then pair your phone with a fresh QR code._
