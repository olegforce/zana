# What's new in 2.3.0

Zana 2.3.0 brings a simpler mobile browser experience, a walkthrough for connecting your iPhone, and more reliable conversations. Long threads open with less unnecessary work, model lists recover from temporary failures, and Inbox replies return to the original conversation. Follow your agents over the internet through your Zana Connect account.

## Use Zana everywhere

Watch the 64-second walkthrough in the in-app release notes: click **Remote access** in the bottom-left, choose your Zana address, paste the connect code, then open that address in Safari on your iPhone with the same GitHub account. The video includes English narration and captions and plays offline after the update.

[Watch or download the walkthrough](https://github.com/salesforce/zana/blob/b73a6e0409be36c5871cd20e141a1f3ade887006/apps/app/src/assets/release-notes/zana-everywhere.mp4)

## New

- **Zana Connect accounts.** Click Remote access in the bottom-left, get a connect code through GitHub, choose your Zana address, and paste the code into Zana. Open that address in Safari on your iPhone, sign in with the same GitHub account, and choose Open Zana.
- **A simpler mobile home.** Find all your agents in one searchable menu, with project labels, live working indicators, and clear attention states. New agent, Inbox, and Agents are close at hand; More opens a searchable picker for your other tools and plugins.
- **Phone setup guidance.** Phone settings walks you through browser access. The native mobile app is marked as coming soon.
- **Canvas on mobile.** Choose Kanban, List, or Canvas from Agents. Opening an agent gives its thread or terminal the screen.
- **Attach screenshots from your phone.** Choose images, preview or remove them, and send them with your message.
- **Refresh models without restarting.** Settings → AI Harness adds Recalculate models, and the command palette adds Refresh models. Both update the model lists used by Modern and CLI Agents, with progress and failure feedback.

## Improved

- **More room for conversations.** Mobile agents use one header row. Menus and side panels fill the screen, with clear close and back controls. Long sent messages have a compact preview with Show more, and desktop git/review strips stay out of the mobile composer.
- **A composer built for touch.** Larger harness and model pickers, an expanded writing view, and readily accessible Edit/Full access controls make it easier to configure and send a message. Secondary run settings use a clearer layout.
- **Inbox and documents on small screens.** Cleaner inbox rows and detail actions reduce clutter. Inbox videos play inline with playback and seeking controls. Selecting a Library document opens a full-width reading view with a way back to the list. Scheduler, Tasks, and PR Monitor also use more compact mobile layouts.
- **Steadier mobile navigation.** Agent lists keep their order as work progresses and hide ended agents. Swipe right or use Close to dismiss an agent, and return to Agents in one tap. The project picker supports touch scrolling and stays usable with the phone keyboard open.
- **Settings and navigation.** Search stays available as you scroll the menu. Settings has a consistent return path, and Share, Reload, and This device are tucked into the menu's actions.
- **Remote connection recovery.** Relay connections use heartbeats and reconnect after interruptions.
- **Modern threads in the menu bar.** The desktop menu bar popover includes Modern threads alongside CLI Agents.
- **Salesforce project creation.** Create a Salesforce project after signing into an org, with the project and org connection kept together.
- **Git marketplace sources.** Add supported Git repository catalogs when browsing and installing plugins.
- **Inspectors keep your chosen size.** Agent and thread inspectors remember their resized dimensions and scale with the app window. Docs cards open beside the visible conversation, including inside inspectors and split panes.
- **Clearer diagnostics.** Bounded, credential-redacted logs record background-service failures and identify the running build to help diagnose installation and recovery problems.

## Fixed

- **Conversation loading.** Messages appear as soon as the timeline is available, without waiting for slower thread metadata. Collapsed command and tool rows load their full output when expanded, reducing work when opening large conversations.
- **Model-list recovery.** Temporary discovery failures retry automatically. Reconnecting a machine or returning after a login or configuration change refreshes stale lists, while the last successful list stays visible during refresh. Newly discovered models are also available to launch checks.
- **Inbox opens the original thread.** Open and reply actions return to the conversation that created a report, including archived threads. Replies and structured answers no longer fall back to a replacement CLI Agent when the original is a Modern thread.
- **Codex Send now and Stop.** Commands use the provider's active turn identity, fixing rejected queued-message sends and interruptions caused by mismatched turn IDs.
- **Browser previews in inspectors.** Loaded websites display correctly inside agent inspectors, and Reload or resubmitting the current address refreshes them. Reopening an equivalent preview reuses its tab when the browser profile and control permissions allow it.
- **Background-service recovery.** If a desktop service stops unexpectedly, Zana offers a restart and reports unavailable operations promptly. A failed project lookup no longer appears as an empty project list. Restarting remains an explicit action because it ends surviving agents.
- **Remote daemon updates.** Updates validate the replacement before switching versions and roll back if startup fails. Installation and repair check process ownership, and reconnects restore the correct connected status.
- **Upload progress.** The upload indicator sits inside the composer with a spinner and consistent spacing.
- **Mobile panel themes.** Agent side panels and diffs follow the app's light or dark theme.
- **Voice authentication.** Voice input recognizes the desktop's supported Codex sign-in storage instead of incorrectly asking an already signed-in user to log in again.
- **Plugin installation recovery.** Failed plugin replacements roll back cleanly, and Tasks styles stay contained within the plugin.
- **Background AI configuration.** Thread naming and summaries honor the configured Claude executable after settings migration.
- **Dependency hardening.** Updated transitive HTML-sanitization and UUID dependencies and added bounded handling for malformed URI decoding.
