# What's new in 2.3.3

**Bring your Zana projects into Slack, with a more responsive desktop and more reliable remote connections.** Zana 2.3.3 includes the Slack plugin, working PDF previews, easier project editor actions, and the latest remote-host recovery fixes.

## New

- **Zana for Slack is included.** Connect your projects to Slack, start agents, follow their progress, and continue conversations from Slack threads. Choose which project answers and plugin tools to share.
- **A private report Inbox in Slack.** Opt in to view reports from the projects you have allowed, open their documents, and keep replies in the same conversation.

## Improved

- **Remote connection repair.** Fix connection in the remote CLI composer repairs disconnected hosts through the active Zana Connect service. When a remote machine cannot reach public HTTPS, Zana can transfer its host runtime and reconnect through SSH while preserving its identity.
- **Open projects in your editor.** Editor actions are available from both the project sidebar menu and the focused project's menu.
- **A more responsive desktop.** Terminal output, conversation history, searches, editor loading, and agent views do less unnecessary work while projects are busy.
- **Agent and plugin startup.** Worker-backed providers finish resolving their launch options before execution starts. Bundled plugin assets and startup checks are more reliable in packaged builds.

## Fixed

- Remote CLI model discovery reports the connection problem and offers a repair action when its host is disconnected.
- PDF previews preserve the original file bytes, render correctly, and offer working download actions.
- Terminal commands, remote shell output, and plugin communication avoid several causes of stalled or frozen sessions.
- Project views refresh consistently as agents work and finish, and filesystem watchers avoid unnecessary work in nested repositories.
