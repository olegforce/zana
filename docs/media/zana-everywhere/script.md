# Use Zana everywhere

Final script · 64 seconds · desktop to iPhone Safari

## Storyboard and voiceover

| Time | On screen | Voiceover |
| --- | --- | --- |
| 00–04 | Open on the Zana desktop. Title: **Use Zana everywhere.** | “Use Zana everywhere.” |
| 04–14 | Gently zoom into the bottom-left sidebar. Highlight and click **Remote access**, then **Get a connect code**. | “On your computer, click the Remote access icon in the bottom-left corner, then Get a connect code.” |
| 14–25 | The account page opens. Click **Sign in with GitHub**. Enter **my-domain**, click **Reserve address and get code**, then **Copy code**. Keep **my-domain.zana-ide.com** prominent. | “Sign in with GitHub and enter my-domain. Reserve your address, then copy the connect code.” |
| 25–35 | Return to Zana and paste the code. Let the connection complete. Highlight the connected status and dedicated address together. | “Back in Zana, paste the code. Your computer connects automatically, and your dedicated address is ready.” |
| 35–44 | Transition from the desktop address to an iPhone. Open Safari, enter the same address, and navigate to it. | “Now pick up your iPhone. Open Safari and enter your new Zana address.” |
| 44–52 | Show the browser sign-in with the same GitHub account, followed by the **Open Zana** confirmation. Tap it. | “Sign in with the same GitHub account, then tap Open Zana.” |
| 52–64 | Reveal Zana’s actual mobile kanban inside Safari. Show the agent cards and status tabs, with a gentle scroll. Finish on the board with **Your agents. Everywhere.** Add a quiet footer: **Keep your computer awake and online, with Zana running.** | “And voilà! Your agents, right on your phone. Follow their progress from the kanban, wherever you are.” |

## Production direction

- Keep the polished visual style and the previously approved Ava neural voice, at a relaxed, conversational pace. The final cut runs 64 seconds, including a hold on the kanban at the end.
- Use **my-domain.zana-ide.com** as the illustrated example throughout desktop and iPhone. The narration says “enter my-domain” (pronounced “my domain”) and “your Zana address.”
- Make the address the visual connection between devices: highlight it on desktop, then carry it into Safari’s address bar.
- Frame the account page tightly around the relevant sign-in, address, and code controls. The website also contains mobile-app instructions that do not belong in this browser walkthrough.
- Keep Safari’s browser chrome visible in the final reveal. Show the existing responsive kanban with sample agent cards.
- This video uses Safari throughout the iPhone sequence. Omit native-app screens, installation, QR codes, TestFlight, and phone-pairing prompts.

## Flow review

Checked against the current desktop sidebar, Remote access pairing panel, website address reservation, and browser sign-in components. Pasting a valid connect code starts the connection automatically. Opening the dedicated address in a fresh browser requires the same GitHub account and the **Open Zana** confirmation. The desktop must remain awake, online, and running Zana with Remote access enabled.
