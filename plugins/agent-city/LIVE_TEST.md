# Live verification

1. Build/install/reload using the repository CLI as described in README.md. Check plugin status is `running`.
2. On a host with `experimental_agentsView`, open Agents → World. Verify Agent City appears under Plugins → Installed plugins and has no separate navigation entry. Older hosts keep it installed without exposing World; this is installation verification only.
3. Select a project to enter its cutaway. Check the garage workshop, office, tower floors/lobby/roof and planned-only schedule board. Open a named workstation (both its canvas desk and accessible button), and verify the existing inspector displays that same agent. Back to city/Escape must preserve the previous camera and restore focus. Check the scheduler station and Done pavilion.
   Inside, count exactly one worker per live agent or non-running schedule plan across floors/pages. Idle agents relax, get coffee or stroll; working/needs-you/scheduled agents and clearly labeled plans sit at desks. Moving idle workers must remain clickable. A running plan must not add another worker beside its live session.
4. Pause animation, use status/search filters, verify search highlights results without changing full-population building sizes/lots; verify populated buildings share one map while empty and exited-only projects stay absent, zoom/pan/Fit city, add a project and agent without losing existing plots/seats, find a request on another floor, use the drawn elevator, open a mobile conversation and return to the same interior, and check a small viewport. With reduced motion enabled the motion control must be disabled and the scene still usable.
5. In an isolated test install, edit the heading, run `plugin dev --once`, verify the open view remounts, and disable/re-enable the plugin to verify safe fallback and restoration. Never perform destructive probes on the user's agents.
6. Run `pnpm test:e2e -- e2e/agent-city-plugin.spec.ts` for the automated production-boundary checks in a private Electron app and paired mobile gateway.

The installed host exposes World. The populated-project filter, ambient commuting crowd and current thread harness colors are verified in its native UI after plugin reload. The updated fleet projection adds harness metadata for CLI agents and schedule plans; verify that projection in the private built Electron test. No restart of the user’s active app is needed for plugin-only changes. The optional full-population projection needs the updated host; verify search stability in the private built Electron test and adopt it with the next app update.
