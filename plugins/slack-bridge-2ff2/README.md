# Zana for Slack

Zana for Slack is pre-installed with Zana. Open **Plugins → Zana for Slack → Configuration**, link your account, and connect the Projects you want to use from Slack. No separate plugin download or manual token setup is required for Connect.

Mention `@Zana` in a connected Project channel to start work or continue a task in its thread. You can also message the agent directly; it asks for clarification when the Project is uncertain. The Configuration page controls the default provider/model, private agent chat, report-inbox access, and the answers or plugin capabilities shared with Slack. Report access and channel sharing are opt-in. Keep Zana running on your linked machine.

An existing path-installed `slack-bridge-2ff2` keeps its identity, account link, and settings. Disabled or uninstalled plugins stay that way after an update. The bundled version is available from the Plugins catalogue.

Read [Connect setup](docs/connect-setup.md), [Projects in Slack](docs/projects-in-slack.md), [agent conversations](docs/thread-replies.md), [slash commands](docs/slash-commands.md), [rich answers](docs/rich-results.md), and [capability controls](docs/slack-capabilities.md).

## Development

This source was brought into the core repository from the local Zana for Slack plugin at commit `0700569` (version 0.15.0). Its stable plugin ID preserves existing installations.

From the repository root:

```sh
pnpm --filter zcc-plugin-slack-bridge-2ff2 build
pnpm --filter zcc-plugin-slack-bridge-2ff2 test:coverage
pnpm --filter zcc-plugin-slack-bridge-2ff2 typecheck
pnpm test:e2e -- e2e/slack-builtin.spec.ts e2e/slackbot-mcp.spec.ts
```

Release packaging compiles the server and Configuration UI and includes the capability catalogue, skills, and Mermaid browser script. The installed runtime needs neither this source checkout nor npm dependencies. Mermaid images use a locally installed Chrome or an existing Puppeteer browser cache; the plugin does not download a browser during installation or startup. Without a browser, replies retain readable diagram source.

The capability catalogue is generated by `packages/slack-capabilities/sync.mjs`; regenerate it when the shared Slack policy changes.
